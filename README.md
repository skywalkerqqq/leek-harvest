# 🥬 镰刀与韭菜 (Scythe & Leeks)

> 一片阴郁的韭菜田，一场金融丛林里的权力游戏。你扮演「庄家 / 镰刀」，把散户（韭菜）的钱搬进自己的金库。

一款纯前端、打开即玩的**暗黑讽刺策略经营**小游戏。基于 three.js 构建，用字面化的 3D 动作演绎「割韭菜」的隐喻——引流养肥、挥镰收割，在监管、泡沫与韭菜觉醒之间走钢丝。

[English](README.en.md)

## ✨ 特性

- 🌑 **暗黑写实绿调**：压抑的金融丛林，金色钱币与冷钢镰刀是唯一的高光
- 🌱 **字面化隐喻**：韭菜会生长、上头（FOMO）、恐慌、觉醒跑路；收割时从中间被斩断、上半截倒伏
- 🎯 **30 交易日结算**：段位从「镰刀之王」到「被反割」，另有无限沙盒模式
- 💥 **系统涌现**：引流 → 养肥 → 收割 → 升级 → 风险结算，简单规则耦合出复杂局面
- 🎲 **随机事件**：同行砸盘 / 政策东风 / 黑天鹅 / 韭菜觉醒潮 / 假利好等 8 种带权重事件
- 📈 **经济深度**：泡沫、边际递减、监管热度、口碑、忠诚度多系统联动
- ✨ **后处理**：自包含 Bloom 泛光 + 暗角 + ACES 色调映射
- 🔉 **合成音效**：WebAudio 环境底噪（风声 / 城市嗡鸣）+ 交互音效，无外部资源
- 💾 **本地存档**：localStorage 持久化
- 📱 **响应式**：桌面拖拽 + 移动端双指缩放 / 触控收割

## 🎮 玩法

每回合四阶段 + 风险结算：

1. **引流播种**：直播 / 荐股 / 财富课，把新韭菜拉入场（口碑越低成本越高）
2. **养肥**：话术 + 社群氛围，把韭菜钱包吹肥（边际递减，泡沫越热涨得越快）
3. **收割**：挥镰刀，范围内韭菜按「肥度 × 转化率」变为现金
4. **升级**：宽刃镰刀 / 锋利镰刀 / 危机公关 / 洗白身份

**风险**：收割会累积「监管热度」，满则「请喝茶」没收一半现金并强制终结；韭菜警觉度满了会觉醒跑路、拉低口碑。

## 🚀 本地运行

纯前端、零构建、无后端。由于使用 ES Modules，需用静态服务器打开（不能直接双击 `file://`）：

```bash
cd leek-harvest

# 任选其一
python -m http.server 8000     # Python
npx serve .                    # Node
# 或使用 VS Code 的 Live Server 插件
```

然后浏览器打开 `http://127.0.0.1:8000/`。
